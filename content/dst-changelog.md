{{% changelog %}}

## 2026-08-24
`v1.0.0` `正式版`

- 首个正式版本发布。
- 支持 BM000-BM999 模组数据浏览。
- 支持按模组 ID / 名称搜索。
- 支持正序/倒序切换。
- 新增动态加载，400+ 模组不再卡顿。

## 2026-08-20
`v0.9.0` `测试版`

- 支持搜索模式（searchOnly），页面仅显示搜索结果。
- 新增 all-mods 动态加载方案。
- 适配 hugo-book 主题 CSS 变量。
- 修复了已知问题。

## 2026-08-15
`v0.8.0` `内测版`

- 上线「电脑控制」功能。
- Design 模式支持图片编辑。
- 对话框可一键最小化为悬浮窗小标。
- 修复了已知问题。

## 2026-08-10
`v0.7.0` `内测版`

- 支持 TRAE 移动端连接 TraeCode。
- 修复了已知问题。

## 2026-08-01
`v0.6.0` `内测版`

- 首页增加了「我的文件」入口，可查看新对话里生成的图片、视频、html 产物。
- 通过 "+" 入口，引用"当前项目文件"、"我的文件"、"飞书文档"。快速找到你在当前项目、所有任务、飞书文档中的文件产物。
- 发送任务时，可以不选择文件夹直接发送任务。
- 支持会话分享：分享方式包括链接，二维码，长图，系统分享等。
- 新增反馈入口：可以在设置页中，找到「帮助与反馈」，点击即可提交你对 TRAE 的使用体验与产品建议。
