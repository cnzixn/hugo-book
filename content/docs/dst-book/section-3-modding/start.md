## 模组的组成

- 代码，游戏使用的是 `Lua` 脚本语言，可以让 AI 教你，或者帮你写代码。  
  
- 贴图，用官方工具 Textool 生成，电脑版贴图一般用 `dxt5` 格式。手游联机版贴图格式为 `astc` 格式，也可以使用 `argb` 无压缩格式。
  
- 动画，将电脑版动画文件里的贴图转为 `astc` 或 `argb` 格式。(动画文件使用 Spriter 制作，请自行搜索相关教程)  
  
- 音效，可以直接使用电脑版的音效文件。
