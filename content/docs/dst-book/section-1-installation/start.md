## 安装步骤
-----

{{% steps %}}

1. ## 下载游戏
   - 从 [[游戏文件]](/p/dst-apps) 下载你需要的版本，安装并打开游戏试玩。

2. ## 下载模组
   - 从 [[模组文件]](/p/dst-mods) 搜索并下载你想玩的模组。

3. ## 安装模组
   - 使用 [[iMod]](https://d1.225228.xyz/imod2/) 在线工具，将模组添加到安装包。
   - 安卓玩家可以使用 `MT管理器` 安装模组，参考文章 [[关于 apk/ipa 文件]](/p/dst-about)。
   - 网盘 `游戏文件` 里有提供 `imod2` 工具，跟安装包和模组放在同一目录下，执行就会安装模组。
  
4. ## 签名&安装
   - 玩家需要自学 `apk/ipa` 文件签名并安装的方法。  
   - 安卓玩家使用 `MT管理器` 签名；苹果玩家请搜索“巨魔”、“LiveContainer”相关教程。

{{% /steps %}}
