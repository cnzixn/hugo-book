## 安装步骤
-----

> [!TIP]
> - 安卓玩家请使用 `MT管理器` 签名并安装 `apk` 安装包。  
> - 苹果玩家请搜索“TrollStore ”、“LiveContainer”相关教程。  

{{% steps %}}

1. ## 游戏
   
   从 [[游戏试玩]](/p/dst-apps) 下载，安装并试玩。

2. ## 模组

   从 [[模组分享]](/p/ds-mods) 下载， 使用 [[iMod]](https://d1.225228.xyz/imod2/) 在线工具安装。 

   注：安卓玩家可以使用 `MT管理器` 安装模组，参考文章 [[关于 apk/ipa 文件]](/p/dst-about)。

{{% /steps %}}
