## 安装步骤
-----

> [!TIP]
> - 安卓玩家请使用 `MT管理器` 签名并安装 `apk` 安装包。  
> - 苹果玩家请搜索“TrollStore ”、“LiveContainer”相关教程。  

{{% steps %}}

1. ## 游戏
   - 下载你需要的 [[游戏]](/p/ds-apps)，安装并打开游戏试玩。

2. ## 模组
   - 下载你想玩的 [[模组]](/p/ds-mods)。

3. ## 安装
   - 使用 [[iMod]](https://d1.225228.xyz/imod2/) 在线工具，将模组添加到安装包。
   - 安卓玩家可以使用 `MT管理器` 安装模组，参考文章 [[关于 apk/ipa 文件]](/p/dst-about)。
   - 网盘 `游戏文件` 里有提供 `imod2` 工具，将它和安装包、模组放在同一目录下，执行就会安装模组。

{{% /steps %}}
