## 牛牛信息 HUD（Beefalo Info HUD）

绑定铃铛后，把皮弗娄牛的各项数据直接显示在 HUD 上，并把一整套驯化 / 骑乘相关的增强功能收进同一个设置面板。

### 信息面板显示什么

- 增益（Buff）剩余时间
- 生命
- 骑乘持续时间
- 饥饿
- 服从度
- 驯化度
- 驯化倾向，以及更详细的驯化数据

操作：**左键拖动**调整面板位置，**右键**把当前信息发送出去。

### 驯化倾向怎么判定

| 条件 | 倾向 |
| --- | --- |
| 参考值（总值）最高 | 骑乘型（Rider） |
| 战斗值 > 参考值 | 战斗型（Fighter） |
| 喂养值 > 参考值 | 肥胖型（Pudgy） |
| 三项都低于参考值 | 默认型（Default） |

### 设置

- 上面列出的功能都有独立开关，也可以一键全部关闭
- 面板**左下角有配置按钮**，改专用服务器设置时不用翻配置文件
- 部分功能要求驯化度 **> 5%** 才生效

### 绑定铃铛之后

- **右键食物**快速喂牛（食物种类在 HUD 设置里增删）
- **右键铃铛**上牛，**手持扫帚**解绑（默认关闭）
- 铃铛上会显示这头牛的名字
- 攻击自己的牛需要按强制攻击键（默认 `Ctrl`）
- 骑乘时不会触发陷阱，也不会挡住建筑放置
- 不会引起牛群仇恨，也无法被牛角解绑
- 驯化度不会下降（默认关闭）
- 装鞍后的牛不会发情、不会排便
- 战斗型牛不用先喂食——处于愤怒状态也能直接骑

其余绑定后的功能：

- 用**扫帚**快速更换牛的皮肤
- **防止牛灭绝**：牛会在岩石地形附近重新生成；伏特羊在没有自然刷新点时于湖边生成
- 用铃铛把牛**打包**带走，也可以对自己的牛使用"附身"
- **召回铃铛**：空手点击自己即可召回；铃铛被他人或怪物拿走、甚至被遗忘也能生效
- 掉在地上的铃铛会**指向牛的方向**；对蟹王（隐士 10 级）和熊獾使用对应战利品有同样效果
- 对着**梳妆台使用扫帚**可以清理地面杂物（刷坎普斯有用），清理清单在 `moddir/3439927311/scripts/BeefaloInfoHUD_clean_list.lua`；暗影棋子不会被清理

### 骑乘增强

- 骑乘时可以**建造**（默认关闭）、**打开容器**
- 薇洛骑乘时可以吸取火焰 / 月焰
- 沃拓克斯骑乘时可以灵魂跳跃，**灵魂会给牛回血**
- 附近的牛**共享 50 点生命**（最低 10 点），治疗时 +10 服从度
- 其他零散功能归在设置的「Miscellaneous」里

### 农夫牛（Farmer Beefalo）

- 可以吃种子
- **骑乘 + 锄头**：耕地（HUD 里可切换 9 格 / 10 格）
- **骑乘 + 铲子**：收获并聚拢巨型作物
- **骑乘 + 锤子**：收获并砸开巨型作物
- 骑乘时单次收获会留下坑洞
- 骑乘时做表情可照顾 **12 格**半径内的作物（圣歌为 **24 格**）
- 唱圣歌时有彩蛋
- 可以开采月雹、陷坑、小冰川

另外：牛自带一个背包；**骑乘 + 手杖**可冲锋传送最多 **12 格**（非噩梦鞍要求牛有饥饿值）。

### 默认关闭的可选功能

以下功能默认都是关的，需要自己在设置里打开：

- 用**猫尾鞭**改变驯化倾向
- 骑乘时仍可使用武器（武器在 HUD 里添加）
- **防击退**
- 用**告密的心 / 扭曲的心**复活（普通铃铛牛会留下尸体）
- 不会被甩下鞍
- 移除单次携带限制（选中的铃铛会高亮对应的牛）
- 牛**发光**（半径随驯化度增加）
- 掉落的铃铛可当**系绳**用
- 骑乘时**快速收获**
- **瞬间上鞍**（跳过动画）
- 非本人的牛下线时**铃铛掉落**（掉在猪王附近 / 洞穴入口）
- **攻击保护**（不损失驯化度与服从度）
- **过度喂养保护**
- **可调数值**：驯化速度、各倾向增长速率、刷子效率、骑乘时长、移动速度、攻击、生命、治疗量、回复速率、饥饿、产毛速度、繁殖率
