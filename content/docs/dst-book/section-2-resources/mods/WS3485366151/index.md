## 横板技能施法（Horizontal Skill Casting）


把角色的技能轮盘改写成**横向布局**，并提供高度可自定义的快捷键绑定与瞬时施法。

### 功能

- **横向布局**：用横向技能栏替代原本的径向技能轮盘，默认位于物品栏上方。
- **保持展开**：使用技能后轮盘依然展开；再次右键或按关闭快捷键即可收起。
- **自由拖动**：按住右键把轮盘拖到任意位置，中键重置，位置自动保存。
- **自适应缩放**：自动跟随游戏的 HUD 缩放设置。
- **全角色快捷键**：为支持的角色技能分配专属快捷键。
- **瞬时施法**：用快捷键直接施放，跳过目标选择。
- **连续施法**：施法后自动重新进入目标选择，支持按住快捷键重复施放。
- **冷却显示**：为薇洛与温蒂显示冷却计时，技能轮盘也会显示技能可用状态。

### 支持的角色

| 角色 | 内容 |
| --- | --- |
| 麦斯威尔 | 暗影法术 + 暗影法典补充 + 高礼帽快捷键 |
| 温蒂 | 阿比盖尔指令 + 安抚/激怒切换 + 药剂篮快捷键 |
| 薇洛 | 火焰法术 + 自动火焰攻击 + 火焰吸收快捷键 + 冷却计时 |
| 沃尔特 | 沃比命令轮盘 + 冲刺快捷键 + 双击冲刺开关 + 右键骑乘 |
| 薇诺娜 | 远程命令轮盘 |
| 薇克巴顿 | 横向书籍轮盘，可选切回原径向轮盘 |
| 薇格弗德 | 立即演唱战歌 / 歌曲切换快捷键 + 闪电矛与盾攻击 + 落点标记 |
| WX-78 | 护盾电路快捷键 + 一键附身最近的备份体 |

### 快捷键绑定

- 可为每个支持的角色技能分配专属快捷键。
- **瞬时施法**：可全部启用、全部禁用，或逐个技能单独配置。
- **连续施法**：按住快捷键重复施放，右键取消目标选择。
- **修饰键**：部分功能支持 `Alt`、`Ctrl`、`Shift`。
- 所有快捷键均可自定义，避免与其他模组冲突。

### 角色专属细节

- **薇洛**：自动火焰攻击——攻击可燃目标时自动装备打火机，随后恢复原先的武器；可配置生命阈值、火焰吸收快捷键与冷却显示。
- **薇格弗德**：三首战歌支持瞬时施法与切换快捷键；闪电矛/盾攻击快捷键；落点标记与冷却状态显示。
- **沃尔特**：冲刺快捷键；双击冲刺开关；右键骑乘或下马沃比。
- **麦斯威尔**：暗影法典补充快捷键；暗影法术快捷键；高礼帽快捷键。
- **WX-78**：护盾电路快捷键；一键附身最近的备份体。

此外，本模组还改进了 WX-78 的右键模块动作同步——当客户端模组新增或修改音波、护盾等动作时同样适用。

### 设置与使用

- 打开 暂停菜单 → 设置 → 控制 → **Horizontal Casting**（横向施法），快捷键与功能选项位于列表顶部。
- 修改后点击「应用」。
- 切换轮盘样式后，需要重新打开技能轮盘才能看到新布局。
- 这是**客户端模组**，其他玩家通常无需安装。

### 注意事项

- 横向布局会按当前可用技能动态排列。
- 使用前请先为各角色配置快捷键。
- 瞬时施法仅在通过快捷键施放时生效。
- 连续施法开启后，手动指定目标的法术会在施放后重新进入目标选择，右键可取消。
- 冷却计时仅薇洛与温蒂支持；其他角色主要显示技能可用状态。
- 薇洛火焰攻击的生命阈值需要服务端血量显示模组才能读取目标血量，否则目标会总是被点燃。
