## 箱子的菜单（Chest's Menu）

> 中文草稿：根据创意工坊描述整理，后续可继续校对。

为容器添加一个功能菜单，以下功能**全部可单独开关**。

- 手持扫帚打开容器时，可以隐藏这些按钮。
- **锁定**：锁定格子，锁定格内的物品不会被其他功能取走。鼠标操作：中键点击某个格子（激活时显示锁图标）。

### 功能列表

1. **Dry（晾晒）**：从晾肉架上添加、替换或取走肉 / 肉干。
2. **Cook（烹饪）**：自动烹饪上次准备的料理。增强设置：物品栏缺少食材时会搜索附近的容器。
3. **Store（存放）**：把物品栏中相同的物品转移到箱子。
4. **Sort（整理）**：按数量从多到少排序箱子内容，配合「锁定」可实现自定义排序。
5. **Collect（收集）**：捡起附近地面上相同的物品。
6. **Put In（放入）**：把物品栏中的物品存入箱子；**≤6 格的容器只显示这个按钮**。
7. **Merge（合并）**：把附近建筑里的相同物品合并进箱子。
8. **Clean（清空）**：丢出箱子内的所有物品。
9. **Refresh（刷新）**：把物品的新鲜度恢复到 100%。
10. **Roast（烤制）**：烹饪食物、把原木变成木炭、加热暖石。
11. **Cool（降温）**：降低暖石温度。
12. **Restore（修复）**：恢复书籍耐久。
13. **Perish（腐坏）**：使新鲜度降为 0。

### 手柄操作

| 操作 | 按键 |
| --- | --- |
| 容器锁定 | `Y` |
| 物品栏锁定 | 十字键↑ |
| 打开 / 关闭菜单 | `B`（需先选中一个格子） |
| 切换按钮 | 肩键 |
| 物品栏中的背包 | 选中物品栏时按 `Y` 切换按钮 |
