## 种植助手（Planting Helper）

> 中文草稿：根据创意工坊描述整理，后续可继续校对。

客户端批量种植工具，可用网格方式种植草、树枝、灌木与树木。

### 使用方法

1. 手持任意可种植物品（草丛、树枝、浆果丛等），光标处会出现网格预览：**绿色 = 可种植，红色 = 被阻挡**，预览下方显示当前尺寸（例如 3×4）。
2. `Ctrl` + 滚轮：调整行数（Y）。
3. `Alt` + 滚轮：调整列数（X）。
4. 右键：一次性种完整片区域。

### 智能种植

- 自动从手上、物品栏与背包中取用匹配的植物。
- 采用蛇形路径，之后再回头补上遗漏的格子（例如你正好站着的那一格）。
- 种植过程中网格会锁定并显示实时进度：当前格子高亮，完成的格子会清除。
- 种完整片区域，或材料用尽时自动停止。
- 想中断？按任意移动键即可立刻取消。

### 指示灯与设置

手持可种植物品时，制作按钮旁会出现一个小木牌，其灯光表示状态：

| 灯光 | 含义 |
| --- | --- |
| 黄色 | 就绪 |
| 快闪黄 | 正在调整网格 |
| 绿色 | 正在种植 |
| 常亮绿 | 已完成 |
| 红色 | 此处无法种植 |
| 快闪红 | 被中断——真的不能种 |

点击木牌打开设置窗口：

- **Grid Snapping**：开 / 关，把植物锁定到固定的世界网格。
- **Spacing**：1 ～ 5，植物之间的间距。

设置会自动保存并在下次进入时恢复。网格尺寸同样会被记住，但在 5 / 10 / 20 分钟（或从不）未种植后会静默重置为 1×1，避免拿起植物时瞬间闪出巨大的预览。

### 注意事项

- 兼容 Geometric Placement：会同步 GP 的设置并使用相同的世界网格（目前仅支持方形网格）。
- **仅客户端**生效。
- 对可种植的植物、树木、树枝与灌木有效；建筑与其他可部署物会被有意忽略。
