## 状态变化显示（Stat Change Display · 2026 优化版）

> 中文草稿：根据创意工坊描述整理，后续可继续校对。

显示三项属性（饥饿、理智、生命）的变化数值。

**前记**：原版模组在开启无敌模式挂机时，数字会不停弹出；因此作者对原模组做了优化，并加入了不少新功能。原模组为「Three Attributes Change Display」，工坊 ID `1876137475`。

### 本次优化内容

1. 文字新增自动淡出效果。
2. 仅在数值**实际发生变化**时才显示。
3. 代码优化。
4. 数字增加颜色区分。

### 更新日志

- **1.0**：模组发布。
- **1.1**：可以关闭彩色字体。
