## 云霄国度（Above the Clouds）

> 中文草稿：根据创意工坊描述整理，后续可继续校对。

在饥荒联机版中加入 Hamlet 风格的失落猪人城镇。玩家可以探索热带丛林中的贵族猪人社会，访问商店、交易、购买并改造房屋，也可以深入古代猪人遗迹进行寻宝。

模组还加入新的区域、野生生物、季节、物品、材料和配方，目前仍在持续开发中。遇到问题时可通过原页面提供的 GitHub Issues 或 Discord 反馈。
