## 可开采的宝石（Mineable Gems）

> 中文草稿：根据创意工坊描述整理，后续可继续校对。

让开采石头（boulders）时有几率额外掉落宝石，掉落几率可在模组配置中调整。

属于**仅服务器端**模组（server side only），客户端无需安装。作者说明它采用正规 API 方式实现，因此游戏更新几乎不会影响该模组，与现有及未来的其他模组兼容性最好。工坊标签为 `mineable gems`。
