## 刨坑对齐（Snapping Tills）

{{< gallery caption="" href="" >}}
  38662315507C35F8D348C3662B7126FF.png
{{< /gallery >}}

- 装备锄头后，会显示“犁地模式”按钮。
- 直接点击耕地，在点击处最近的“坑位”刨坑。
- 按住“耕地”按钮，优先在当前耕地上刨坑，没有坑位就去下一块耕地。
- 优化模式会优先检查相邻耕地，并根据情况使用 4×4 或 3×3 布局。

-----

植物人，在物品栏点击“种子”，可能会出现 2 个栽种

- 栽种（对土堆）：在选定的土堆上栽种。
- 栽种（放置模式）：此时点击地面直接栽种，会对齐到“坑位”。
